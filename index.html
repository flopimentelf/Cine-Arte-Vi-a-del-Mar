02 / LA EXPERIENCIA PEATONAL

El cuerpo
recorre el espacio.

La percepción peatonal se construye a través de las condiciones del entorno y de la relación que establecemos con él. Cada paso implica observar, interpretar y adaptarse al territorio.

03 / LAS DIMENSIONES

El espacio
también se percibe.

Para observar la experiencia peatonal, el estudio se organiza en tres dimensiones que permiten relacionar las características físicas del territorio con la manera en que se vive el recorrido.

01 / ESPACIO

Apertura y amplitud

¿El espacio se siente abierto o contenido? ¿Permite observar lo que viene? ¿Facilita caminar, detenerse o permanecer?

02 / ORIENTACIÓN

Elementos referenciales

¿Qué elementos llaman nuestra atención? ¿Podemos reconocer dónde estamos? ¿Los referentes ayudan a ubicarnos y comprender el recorrido?

03 / SUPERFICIE

Materialidad

¿La superficie permite caminar cómodamente? ¿Existen desniveles, obstáculos o irregularidades? ¿Cómo cambia el desplazamiento?
